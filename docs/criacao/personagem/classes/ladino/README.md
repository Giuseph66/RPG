# Ladino

ID: `rogue`. Estado documental: especificação para implementação futura; nenhuma lógica implementada.

Livro do Jogador fornecido, cap. 3 — Classes, pp. impressas 89–93, PDF 88–92. Pack `phb-ptbr-local-2017`; IDs independentes da tradução.

## Criação

| Campo | Regra |
|---|---|
| Atributo principal | Destreza; Inteligência/Carisma segundo foco |
| Dados de Vida | d8; primeiro nível personagem 8+CON; níveis posteriores 1d8 ou 5, somando CON |
| Armaduras | Leves |
| Armas | Simples, bestas de mão, espadas longas, rapieiras, espadas curtas |
| Ferramentas | Ferramentas de ladrão |
| Resistências | Destreza, Inteligência |
| Perícias | 4: Acrobacia, Atletismo, Atuação, Enganação, Furtividade, Intimidação, Intuição, Investigação, Percepção, Persuasão, Prestidigitação |

Equipamento inicial da classe, acrescido do antecedente: Rapieira OU espada longa; arco curto + aljava + 20 flechas OU espada curta; pacote de assaltante OU aventureiro OU explorador; couro; 2 adagas; ferramentas de ladrão. Espada longa é opção escrita na fonte. Não interpretar item oferecido como concessão de proficiência. Cada OU é escolha exclusiva e mantém proveniência.

## Ficha e ações

Personagem mostra nível da classe, subclasse, atributos, proficiências, Dados de Vida, escolhas e recursos. Ações oferece apenas recursos adquiridos/elegíveis, custo, alcance, duração, gatilho, recuperação e explicação das restrições. Recursos primários têm versão compacta no header e detalhada no painel; falta de usos mantém ação legível e desabilitada. Dados derivados não são gravados como verdade independente.

## Multiclasse opcional

Pré-requisito para entrada/saída: Destreza 13; conferir também todas classes envolvidas. Ao entrar após primeiro nível: Armadura leve; 1 perícia da classe; ferramentas de ladrão. Não ganhar novamente equipamento inicial nem resistências iniciais. HP usa regra de nível posterior, BP usa nível total; características usam nível desta classe. Fonte: cap. 6 — Opções de Personalização, pp. impressas165–167, PDF164–166.
