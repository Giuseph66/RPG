# Bárbaro

ID: `barbarian`. Estado documental: especificação para implementação futura; nenhuma lógica implementada.

Livro do Jogador fornecido, cap. 3 — Classes, pp. impressas 46–50, PDF 45–49. Pack `phb-ptbr-local-2017`; IDs independentes da tradução.

## Criação

| Campo | Regra |
|---|---|
| Atributo principal | Força; Constituição secundária |
| Dados de Vida | d12; primeiro nível personagem 12+CON; níveis posteriores 1d12 ou 7, somando CON |
| Armaduras | Leves, médias, escudos |
| Armas | Simples e marciais |
| Ferramentas | Nenhuma |
| Resistências | Força, Constituição |
| Perícias | 2: Adestrar Animais, Atletismo, Intimidação, Natureza, Percepção, Sobrevivência |

Equipamento inicial da classe, acrescido do antecedente: Machado grande OU arma marcial corpo a corpo; dois machados de mão OU arma simples; pacote de aventureiro; 4 azagaias. Não interpretar item oferecido como concessão de proficiência. Cada OU é escolha exclusiva e mantém proveniência.

## Ficha e ações

Personagem mostra nível da classe, subclasse, atributos, proficiências, Dados de Vida, escolhas e recursos. Ações oferece apenas recursos adquiridos/elegíveis, custo, alcance, duração, gatilho, recuperação e explicação das restrições. Recursos primários têm versão compacta no header e detalhada no painel; falta de usos mantém ação legível e desabilitada. Dados derivados não são gravados como verdade independente.

## Multiclasse opcional

Pré-requisito para entrada/saída: Força 13; conferir também todas classes envolvidas. Ao entrar após primeiro nível: Escudos, armas simples e marciais. Não ganhar novamente equipamento inicial nem resistências iniciais. HP usa regra de nível posterior, BP usa nível total; características usam nível desta classe. Fonte: cap. 6 — Opções de Personalização, pp. impressas165–167, PDF164–166.
