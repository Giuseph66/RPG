# Feiticeiro

ID: `sorcerer`. Estado documental: especificação para implementação futura; nenhuma lógica implementada.

Livro do Jogador fornecido, cap. 3 — Classes, pp. impressas 77–82, PDF 76–81. Pack `phb-ptbr-local-2017`; IDs independentes da tradução.

## Criação

| Campo | Regra |
|---|---|
| Atributo principal | Carisma; Constituição secundária |
| Dados de Vida | d6; primeiro nível personagem 6+CON; níveis posteriores 1d6 ou 4, somando CON |
| Armaduras | Nenhuma |
| Armas | Adagas, dardos, fundas, bordões, bestas leves |
| Ferramentas | Nenhuma |
| Resistências | Constituição, Carisma |
| Perícias | 2: Arcanismo, Enganação, Intuição, Intimidação, Persuasão, Religião |

Equipamento inicial da classe, acrescido do antecedente: Besta leve + 20 virotes OU arma simples; bolsa de componentes OU foco arcano; pacote de explorador OU aventureiro. A fonte termina a lista aí; não acrescentar adagas ausentes. Não interpretar item oferecido como concessão de proficiência. Cada OU é escolha exclusiva e mantém proveniência.

## Ficha e ações

Personagem mostra nível da classe, subclasse, atributos, proficiências, Dados de Vida, escolhas e recursos. Ações oferece apenas recursos adquiridos/elegíveis, custo, alcance, duração, gatilho, recuperação e explicação das restrições. Recursos primários têm versão compacta no header e detalhada no painel; falta de usos mantém ação legível e desabilitada. Dados derivados não são gravados como verdade independente.

## Multiclasse opcional

Pré-requisito para entrada/saída: Carisma 13; conferir também todas classes envolvidas. Ao entrar após primeiro nível: Nenhuma. Não ganhar novamente equipamento inicial nem resistências iniciais. HP usa regra de nível posterior, BP usa nível total; características usam nível desta classe. Fonte: cap. 6 — Opções de Personalização, pp. impressas165–167, PDF164–166.
