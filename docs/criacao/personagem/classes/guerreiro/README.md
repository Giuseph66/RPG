# Guerreiro

ID: `fighter`. Estado documental: especificação para implementação futura; nenhuma lógica implementada.

Livro do Jogador fornecido, cap. 3 — Classes, pp. impressas 83–88, PDF 82–87. Pack `phb-ptbr-local-2017`; IDs independentes da tradução.

## Criação

| Campo | Regra |
|---|---|
| Atributo principal | Força ou Destreza; Constituição; Inteligência para Cavaleiro Arcano |
| Dados de Vida | d10; primeiro nível personagem 10+CON; níveis posteriores 1d10 ou 6, somando CON |
| Armaduras | Todas, escudos |
| Armas | Simples e marciais |
| Ferramentas | Nenhuma |
| Resistências | Força, Constituição |
| Perícias | 2: Acrobacia, Adestrar Animais, Atletismo, História, Intuição, Intimidação, Percepção, Sobrevivência |

Equipamento inicial da classe, acrescido do antecedente: Cota de malha OU gibão de peles + arco longo + 20 flechas; arma marcial + escudo OU 2 armas marciais; besta leve + 20 virotes OU 2 machados de arremesso; pacote de aventureiro OU explorador. Preservar gibão de peles escrito nesta fonte. Não interpretar item oferecido como concessão de proficiência. Cada OU é escolha exclusiva e mantém proveniência.

## Ficha e ações

Personagem mostra nível da classe, subclasse, atributos, proficiências, Dados de Vida, escolhas e recursos. Ações oferece apenas recursos adquiridos/elegíveis, custo, alcance, duração, gatilho, recuperação e explicação das restrições. Recursos primários têm versão compacta no header e detalhada no painel; falta de usos mantém ação legível e desabilitada. Dados derivados não são gravados como verdade independente.

## Multiclasse opcional

Pré-requisito para entrada/saída: Força 13 OU Destreza 13; conferir também todas classes envolvidas. Ao entrar após primeiro nível: Leves, médias, escudos, armas simples e marciais. Não ganhar novamente equipamento inicial nem resistências iniciais. HP usa regra de nível posterior, BP usa nível total; características usam nível desta classe. Fonte: cap. 6 — Opções de Personalização, pp. impressas165–167, PDF164–166.
