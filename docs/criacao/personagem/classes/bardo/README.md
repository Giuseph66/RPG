# Bardo

ID: `bard`. Estado documental: especificação para implementação futura; nenhuma lógica implementada.

Livro do Jogador fornecido, cap. 3 — Classes, pp. impressas 51–55, PDF 50–54. Pack `phb-ptbr-local-2017`; IDs independentes da tradução.

## Criação

| Campo | Regra |
|---|---|
| Atributo principal | Carisma; Destreza secundária |
| Dados de Vida | d8; primeiro nível personagem 8+CON; níveis posteriores 1d8 ou 5, somando CON |
| Armaduras | Leves |
| Armas | Simples, bestas de mão, espadas longas, rapieiras, espadas curtas |
| Ferramentas | 3 instrumentos musicais |
| Resistências | Destreza, Carisma |
| Perícias | 3 quaisquer |

Equipamento inicial da classe, acrescido do antecedente: Rapieira OU espada longa OU arma simples; pacote de diplomata OU artista; alaúde OU instrumento; couro; adaga. Não interpretar item oferecido como concessão de proficiência. Cada OU é escolha exclusiva e mantém proveniência.

## Ficha e ações

Personagem mostra nível da classe, subclasse, atributos, proficiências, Dados de Vida, escolhas e recursos. Ações oferece apenas recursos adquiridos/elegíveis, custo, alcance, duração, gatilho, recuperação e explicação das restrições. Recursos primários têm versão compacta no header e detalhada no painel; falta de usos mantém ação legível e desabilitada. Dados derivados não são gravados como verdade independente.

## Multiclasse opcional

Pré-requisito para entrada/saída: Carisma 13; conferir também todas classes envolvidas. Ao entrar após primeiro nível: Armadura leve; 1 perícia qualquer; 1 instrumento. Não ganhar novamente equipamento inicial nem resistências iniciais. HP usa regra de nível posterior, BP usa nível total; características usam nível desta classe. Fonte: cap. 6 — Opções de Personalização, pp. impressas165–167, PDF164–166.
